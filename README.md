# 샵풀무원 리뉴얼 — 학습용 메인 페이지 시안

## 실행
`index.html`을 브라우저에서 열거나 VS Code Live Server로 실행합니다. CSS와 JavaScript는 각각 `css/style.css`, `js/main.js`에 분리되어 있습니다.

## 디자인 근거
- IA/와이어프레임 순서: 헤더 → HERO → 상품 추천 → 베스트 → 신상품 → 일일배달 → 혜택 → 모든 브랜드 → 푸터.
- 헤더·혜택·브랜드: 농심몰 참고. HERO·일일배달: 하이스토어 참고. 추천·신상품: 정원e샵 참고. 베스트·푸터: 아워홈몰 참고.
- 핵심 문제: 프로모션 간 우선순위 경쟁, 구매 목적 혼재, 상품 비교 어려움(제공된 분석 PDF 12~14페이지).
- 색상: #009333, #80C342. 보조 색상은 UI 가독성을 위해 추가. 폰트: Pretendard(CDN, 대체 폰트 포함).

## 반드시 확인할 점
- **비공식 학습용 목업**입니다. 제품 이름은 설명용 예시이며 실제 상품·출시·가격·할인·배송 정보를 나타내지 않습니다.
- 상품 사진은 Unsplash 이미지 URL을 참조합니다. **실제 샵풀무원 제품 사진이 아니며** 인터넷 연결이 필요합니다. 실제 공식 상품 이미지 및 이용 허가된 리소스로 교체해야 실서비스 시안으로 활용할 수 있습니다.
- 실제 장바구니, 결제, 검색, 로그인, 회원가입, 쿠폰 발급, 정기배송 신청 기능은 없습니다. 찜과 장바구니 숫자는 브라우저 화면에서만 동작합니다.
- 로고는 사용자가 제공한 SVG를 `assets/logo.svg`에 복사했습니다.
- 참고 사이트의 레이아웃 원리를 적용했으며 이미지·색상·카피를 그대로 복제하지 않았습니다.

## 와이어프레임과의 차이
1. HERO는 좌우 미리보기 대신 풀 너비 1장 슬라이드로 구현: 반응형에서 콘텐츠 가독성을 우선한 변경. 원 구조를 원하면 `hero-slide` 폭을 줄이고 양옆 슬라이드를 노출할 수 있습니다.
2. 상품 추천은 대표 상품 + 3개 상품으로 단순화: 원안의 대표 상품 + 4개 상품(2×2) 구조는 `recommend-grid`의 열과 상품 개수를 조정하면 됩니다.
3. 혜택은 3열 1행만 구현: 원안의 3열 2행 및 자동 롤링은 아직 구현하지 않았습니다. 임의의 실제 이벤트를 만들지 않기 위해 예시 카드 3개로 제한했습니다.
4. 베스트는 5개 가로 상품과 이전/다음 버튼으로 구현: 원안 중앙 강조형 슬라이드 효과는 중앙 카드 테두리와 위치로 표현했습니다.
5. 브랜드 탭은 예시로 풀무원·지구식단·올가 3개를 구현했습니다. 공식 브랜드별 실제 상품 매핑은 확인 후 확장해야 합니다.
